# Amending the constitutions

These rules govern every change to `CONSTITUTIONS.md`, `INIT.md`, and `PYTHON.md`.

Every section of `CONSTITUTIONS.md` above the Python rules is agnostic to any specific project, programming language, framework, and deployment.

A principle that Principles Live in the Repository sends to `CONSTITUTIONS.md` earns a new clause only when it is orthogonal to every existing clause and important enough to enforce in any development work. A transient, session-specific action does not qualify.

A clause is phrased as the general principle behind the case that prompted it, with every condition and detail that held only in that case removed. An example stays only when it stands for a category that any reader recognizes, and every other example is deleted or generalized until it does. The clause holds in any specific tree, and every name in it is known to any reader of `CONSTITUTIONS.md`.
